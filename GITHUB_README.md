## 🎯 The Problem

Every year, millions of loan applicants are rejected with no explanation. Traditional rule-based systems are:
- **Inconsistent** — different officers, different decisions
- **Opaque** — applicants have no way to improve their profiles
- **Legally risky** — GDPR and Fair Lending laws require explainability

LoanSense AI solves all three. It provides a consistent, data-driven decision **plus** a feature-level explanation that any applicant can understand and act on.

## 🚀 Quick Start

### Option 1: Docker Compose (Recommended)

```bash
git clone https://github.com/yourusername/loansense-ai
cd loansense-ai

# 1. Train the model (generates ./artifacts/)
jupyter nbconvert --to notebook --execute notebook/loan_xai_system.ipynb

# 2. Start API + UI together
docker-compose up --build

# 3. Open in browser
# API docs: http://localhost:8000/docs
# UI:       http://localhost:8501
```

### Option 2: Local Development

```bash
# Install dependencies
pip install -r requirements.txt

# Train model
cd notebook && jupyter notebook loan_xai_system.ipynb

# Start API
cd ../api && uvicorn main:app --reload --port 8000

# Start UI (new terminal)
cd ../ui && streamlit run app.py
```

## 🔌 API Reference

### `POST /predict`

Submit a loan application and receive a decision with explanation.

**Request:**
```json
{
  "loan_amount": 15000,
  "interest_rate": 12.5,
  "annual_income": 75000,
  "dti": 18.5,
  "credit_score": 720,
  "emp_length_yrs": 5,
  "num_credit_lines": 12,
  "delinq_2yrs": 0,
  "months_since_last_delinq": 24,
  "pub_rec": 0,
  "home_ownership": "RENT",
  "loan_purpose": "debt_consolidation"
}
```

**Response:**
```json
{
  "decision": "APPROVED",
  "approval_probability": 0.8732,
  "confidence_band": "High",
  "top_factors": [
    {
      "feature": "credit_score",
      "display_name": "Credit Score",
      "raw_value": 720,
      "shap_value": 0.1834,
      "direction": "positive",
      "human_label": "Helps your application"
    },
    ...
  ],
  "plain_english": "Congratulations! Your application has been approved...",
  "model_version": "1.0.0",
  "inference_time_ms": 23.4
}
```

## 🔬 XAI Deep Dive

### Why SHAP over Feature Importance?

| Method | Type | Consistent | Local | Fast |
|--------|------|-----------|-------|------|
| XGBoost built-in | Global | ❌ | ❌ | ✅ |
| Permutation | Global | ✅ | ❌ | ✅ |
| LIME | Local | ❌ | ✅ | ✅ |
| **SHAP** | Both | **✅** | **✅** | **✅** |

SHAP is the only method that satisfies all three desirable XAI properties:
1. **Local accuracy** — explanations sum to the actual prediction
2. **Missingness** — missing features have zero contribution
3. **Consistency** — if a feature always matters more, it always has higher SHAP value
